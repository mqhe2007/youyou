# Hero 视觉验收

**final result: passed**

## 对照证据

- 视觉真值：[用户提供的右侧视觉稿](./public/images/hero-reference-stage.png)，916 × 887 px。
- 实现页面：[1440 × 900 截图](./design-qa/hero-1440.png)，`http://127.0.0.1:4173/`，浅色、页面顶部、DPR 1。
- 同画面对照：[视觉稿与实现右侧局部](./design-qa/reference-vs-implementation.png)。实现从页面截图裁出 681 × 659 px 的右侧构图，再归一化到 916 × 887 px；这里只比较构图，放大后的字边清晰度不作为实际显示质量判断。
- 浏览器验收视口：1440 × 900、1280 × 800、1024 × 768、768 × 1024、390 × 844。1024px 及以上保留完整视觉稿构图；更窄的屏幕改为单独突出真实客户端截图。各视口均无水平溢出。

## 发现与迭代

1. **P1：初版缺少手写字、雏菊相纸及完整黄色印记。** 使用用户提供的视觉稿作为装饰底层，覆盖稿中概念化的手机界面，叠放真实客户端截图。对照图中两侧手写字、三张相纸、黄色印记和弧线均与来源保持同一相对位置。
2. **P2：右侧初版宽度超过半屏，且图片底色出现矩形边界。** 将构图限制为 `min(50vw, 680px)`；实测在 1440px 视口为 680px，在 1280px 为 640px，在 1024px 为 512px。移除阻止背景混合的隔离层，采用 darken 混合并在底边渐隐。最终页面截图中没有硬矩形色块边界。
3. **P2：大标题尾字曾被右侧图片遮挡。** 将桌面标题字号上限调至 64px，并在窄屏对标语作有意换行。最终截图中标题完整可见。

## 最终检查

- **字体与文案：** 主标题为应用标语“轻松管理人生影相。”；原描述放入正文。视觉稿内手写文案保持原图像，不重绘字形。手机内使用真实客户端的字体与内容。
- **布局与间距：** 桌面右侧小于或等于半屏，手机、相纸、笔记及黄色印记的相对位置与来源相符；内容不遮挡左侧标题和操作入口。
- **色彩：** 装饰背景与页面 `--surface` 融合，底部自然过渡；黄色重点与页面操作按钮统一。
- **图像：** 装饰沿用用户给定的参考图。手机屏幕由真实客户端截图覆盖；照片是演示素材，页内明确标注。聚焦区域对照已经在同一图片里检查，无需另做图标局部图。
- **交互：** 首页“下载客户端”打开 `/download`，在 GitHub 接口不可用时仍显示已核验的 v0.3.1 APK 链接；“了解如何使用”打开 `/quickstart`。外部 GitHub 请求失败会显示回退提示，不阻断下载。
- **浏览器错误：** 预览重启后的开发者日志没有新增 error。
- **构建：** `npm run build` 通过，包含 TypeScript 检查与静态导出。开发预览曾因构建共用 `.next` 缓存短暂失效，清理缓存并重启后页面恢复；最终截图取自恢复后的浏览器页面。

**剩余 P0/P1/P2：无。**
